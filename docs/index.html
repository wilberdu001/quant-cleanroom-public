METHOD / v1.0
01 · 原始数据永远可追溯
输入记录保持原样，转换过程创建新的快照。合成数据保存种子、污染强度、标的和 as-of 截止时刻；导入数据保存在当前浏览器内存中。隔离记录保留原始 ID 与原因，方便定位上游数据问题。
02 · 时间是量化数据的一部分
时间戳表示 K 线开盘时间，统一为 UTC 毫秒，频率为 1 分钟。只有 timestamp + 60s ≤ asOf 的 K 线才进入研究集。随机池使用固定历史时窗；导入文件的无时区日期将被拒绝，避免按电脑本地时区解释。
03 · 缺口与坏行情不能被悄悄抹掉
价格必须为正，成交量必须非负，OHLC 须符合高低价约束。非法记录隔离；缺失分钟只标记，不前向填充价格，不将缺失成交量变成零。间隔不是 1 分钟时，不计算该行的分钟收益。单一来源无法判断真实极端行情与坏 tick，因此 MAD 异常仅标记，等待核验，不做 winsorization。
04 · 用过去的信息构造特征
异常检测用过去最多 60 个收益校准，至少 20 个历史收益才能检测。20 分钟风险估计排除当前收益，缺口或异常会重置窗口；信号取前一分钟收益。tradable 仅表示本演示的数据门槛通过，并不等于可以成交。收盘信号应在收盘后才下单，回测还需显式建模计算延迟、下一条可成交报价、滑点和费用。
05 · 清洗规则需要匹配市场
当前样本模拟连续交易的加密现货，不包含企业行动、退市、幸存者偏差与交易所日历。迁移到股票时，需增加交易日历与复权版本；处理基本面时，需增加公告时间与 point-in-time join；做盘口研究时，需记录序列号、撤单、撮合与双时钟延迟。本工具聚焦分钟 OHLCV 的研究准备。
06 · 复现你的实验
点击“下载可运行研究包”将获得 ZIP：包含自包含的 research.ipynb、research.py、同源 cleaning.py、原始数据、依赖与运行说明。使用 Python 3.11+，安装依赖后可以离线复现。VS Code 脚本支持 # %% 单元格；Notebook 按步输出 pandas DataFrame，并生成 matplotlib 图表。CSV 导出随当前表格视图变化，隔离记录也可单独下载。
快速开始
  • 在随机池选择种子和污染强度，重建同一份输入。
  • 从第 1 步向后检查代码、快照、隔离原因和缺口。
  • 调整 MAD 阈值，观察异常数与就绪样本数的变化。
  • 修改随机种子和污染强度，比较不同数据缺陷对研究就绪样本的影响。
  • 保留实验包与 as-of 时刻，再将数据用于策略研究。
