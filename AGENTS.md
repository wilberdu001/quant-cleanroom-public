# Public showcase boundary

This is a curated public quant research demonstration. Include only reviewed generic data-cleaning methods, clearly labelled synthetic fixtures, educational notebooks and client-side visualization. Never copy production market snapshots, account/user records, credentials, deployment identity or Git history from the complete private project.

Changes should form meaningful, verified milestones. Commit and push each completed milestone separately; do not manufacture empty commits, backdate work or split changes solely to inflate contribution counts.

The owner authorizes reviewed pushes to https://github.com/wilberdu001/quant-cleanroom-public and publication of the static demo on GitHub Pages. Keep the complete project and its existing Site private.

## English-only public content

Keep all public UI text, documentation, code comments/docstrings, notebook explanations, sample provenance, screenshots, and release notes in English. Do not change the private project's language. Regenerate the notebook, script, and static demo from their shared sources, then run the English-only release check before pushing.
